# fuaran-core-py

The Fuaran Core spine in Python: canonical JSON with its proved grammar and parse limits,
the number form, SHA-256 content addresses, tree and op apply, the op-stream chain and
the DAG. It certifies against the conformance vectors the .NET reference
([fuaran-core](https://github.com/Fuaran-Core/fuaran-core)) emits, and declares its
compliance row by row in `host-compliance.json`.

## Status

Under construction (Phase 485): the spine is being moved here from the Python UI host.
